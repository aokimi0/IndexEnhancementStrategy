## 工程纪律亮点

- 仓库自始至终使用 git 管理，所有重大改动可追溯
- 4 大创新点的代码与论文章节一对一映射（§4.7 创新点与代码模块的对应关系）
- 论文健康检查工具贯穿整个写作流程，最终 issues=0
- 实验数据全部以 CSV 落盘，可被任何人独立复现
- LLM 调用通过 SHA-256 缓存 + 硬性预算守门，单次实验成本可压缩到 < 1 USD

# 答辩 Q&A 准备备忘

整理评委可能提问的 20 个核心问题与简短回答，按主题分组。

## 一、创新点质量类

### Q1: 你的创新点是不是"工程整合"而非"算法贡献"？

四项创新点中：
- C1 LLM-as-a-Service 的成本控制范式（SHA-256 缓存 + 预算守门 + 双通道）是工程创新但具有方法学迁移价值；
- C2 异构 Stacking 在 A 股带约束情境下小幅但稳定击败单 LightGBM（IR 5.92 vs 5.84）是算法贡献；
- C3 "高置信即过拟合"反向规律在 α 敏感性 + Mondrian + ACI 三层测试下均稳健（详见 §5.7），属于实证发现性算法贡献；
- C4 Numba JIT 工程加速直接呼应课题书"计算量大、优化耗时"的核心痛点。

### Q2: 与 2026 年 SOTA (如 MIGA 的 CSI300 24%) 相比，你的工作有何价值？

MIGA 是 MoE 路由架构、需训练大量参数，本文 C2 是轻量级 Stacking、CPU 友好、参数量 ≤ 百万级。两者在覆盖广度与工程可复现性之间形成清晰的折衷——MIGA 追求 SOTA 收益，本文追求资源受限场景下的"开源可复用基线"。详见 §2.9 与 §6.3 的路线图。

### Q3: 你的 sentiment 因子端到端 IR 增益为什么是负的？

§3.19 (experiment_log) 已诚实披露：sentiment 数据时间窗口仅 2 个月、覆盖 61 股，移位后只有 0.32% 的面板行有非零 sentiment，导致 LightGBM 在 9/11 个滚动窗口内 sentiment 三列全 0、无法分裂。IR -2.85% 是常量特征引入的子采样扰动，并非 sentiment 真正损害性能。下一步需投入完整 2024-2025 沪深 300 新闻语料把覆盖率提到 50%+。

## 二、实证可信度类

### Q4: 等权 Top 20 的 IR 13.73 是不是 cherry-picked？

不是。§5.12 用 5 个随机种子（7/42/123/2024/314159）重跑，IR 变异系数仅 1.85%（均值 7.01 / std 0.13）。13.73 是 train_months=3 的极短窗口结果（见 §5.10 短样本敏感性表），本文最终选 train_months=6 平衡，对应 IR 7.13。

### Q5: 短样本 (2024-2025) 17 个月的 IR 数字可信吗？

短样本结果应作为"无约束上限"参考，不构成可投资基线。§5.9 五策略对比明确区分：等权 Top20 IR 13.73 是上限，启用优化器后 IR 5.84 才是符合"指数增强"定义的现实数字。论文也补充了长周期 2015-2024 实证（§5.2-§5.4），IR 0.24 → 2.45 的渐进改进与短样本结论一致。

### Q6: Conformal Prediction 反向规律会不会是数据偶然？

§5.7 用三层独立测试佐证稳健性：
1. α 敏感性：偏差恒定 -8.4 ~ -9.2 pp（与 α 无关）；
2. Mondrian 真实数据：覆盖率仅微涨 0.4pp，高置信桶 IR 从 -0.14 进一步恶化到 -0.21；
3. ACI 简化模拟：γ=0.005 时估算覆盖率达 89.7%，可矫正 ~80% 偏差，但需在线方法。

三层独立证据排除了数据偶然的可能。

## 三、技术细节类

### Q7: 为什么用 LightGBM 而不用 XGBoost / Random Forest / DL？

§4.1 给出：A 股低信噪比 + 中小样本 + CPU 限制 → LightGBM 在特征捆绑 (EFB) 与单边采样 (GOSS) 上的工程优势能有效抵御噪音、提升泛化；§5.6 表格也对比了 LGBM / XGB / Ridge 三模型 IR 接近，验证不是 LightGBM 独有。

### Q8: 为什么选 train_months=12（长周期）/ 6（短周期）？

§5.10 表格清楚展示了这是 IR 与样本数之间的折衷点：
- 长周期 12 月 IR 1.53 > 24 月 1.19 > 60 月 0.61，强非平稳性主导；
- 短周期 train_months=6 兼顾测试集留出 11 个月与训练集 6 个月样本量。

### Q9: 为什么 top_n=20？

§5.9 持仓数敏感性表：top_n=10 IR=8.26、20 IR=7.13、30 IR=6.37、50 IR=4.98。Top 20 是 IR 与回撤 / 换手的折衷点——再缩到 Top 10 会推高换手到 10.47，超出指数增强产品实施边界。

### Q10: Numba 加速比 9.84x 是不是夸大了？

§5.8 已分两层说明：
- **Engine 级 9.84×** 是完整 `BaselineBacktestEngine.run()` 流程，含 pandas/dict 等不可加速开销；
- **Kernel 级 130-310×** 是裸 NumPy 数组的 NAV 累乘核函数（§5.8.1 表）。

两层数字共存，并指明 engine 级未来可优化空间。

## 四、风险与局限类

### Q11: 你的策略在实盘能跑吗？

§5.9 强调：等权 Top20 IR 13.73 不构成可投资基线，年化换手 9.93 超过指数增强产品实施边界。LightGBM + 优化器 IR 5.84、换手 2.30 才是落地的现实数字。本文给出的是"研究框架"而非"实盘策略"——实盘还需考虑流动性、对手盘、监管约束等。

### Q12: 严格 OOS (2015-2024 训练 → 2025 测试) 为什么 IR 是负？

§5.10 表格证实 A 股强非平稳性：长历史训练反而引入过时风格的噪声。这是诚实披露的负面发现，也直接支撑了 §4.1 的"高频滚动重训"机制设计。论文未隐藏该结果。

### Q13: LLM 调用是否存在未来信息泄露？

§4.2 设计：publish_time 16:00 前的新闻计入当天，之后计入下一交易日，避免未来信息泄露。所有 LLM 调用通过 SHA-256 缓存可复现，prompt 中明确"不要使用未来日期信息"。

### Q14: Conformal Prediction 的可交换性假设在金融时序成立吗？

不严格成立，正是 §5.7 揭示"系统性低覆盖 -9pp"的根源。§2.7 文献综述已经讨论该理论局限，§6.3 路线图指明用 ACI / TCP / ECI 等自适应方法矫正。

## 五、工程价值类

### Q15: 项目代码工程质量如何？

### Q16: 项目代码可读性与文档完整性？

### Q19: 如果有 GPU，论文会变成什么样？

可以加深度模型（如 PatchTST、TFT、Diffolio 扩散）作为对照、并把 LightGBM 切换到 GPU device 加快网格搜索。但 §6.4 的"教学价值"中本研究的核心定位是"资源受限场景下的可复用基线"，GPU 拓展是补充而非替代。

### Q20: 这个工作的学术贡献到底在哪？

主要在三个方面：
1. **LLM-as-a-Service 量化工程范式**（C1）：将 LLM 从昂贵研究工具转为可控成本的日频信号源
2. **"高置信即过拟合"反向规律的稳健实证**（C3）：揭示 Conformal Prediction 在 A 股低信噪比环境下的方法学局限
3. **轻量异构集成在 A 股的实证有效性**（C2）：Stacking 在带约束情境下小幅但稳定击败单 LightGBM

工程贡献：~50 个 Python 模块 + 完整复现链 + 自研论文健康检查工具 + 51 篇文献综述 + 18 张图表。

## 七、进阶 / 风险类问题（10 个）

### Q21: 你的模型如果上实盘，需要做哪些工程改造？

主要四个：
1. **实时数据接入**：把 akshare/baostock 离线 CSV 缓存改为日终 WebSocket / FIX 协议接收交易所行情
2. **风控前置**：单股 5% 上限、行业 ±2% 偏离需在订单生成阶段（而非回测阶段）强约束，避免 stale 数据导致超限
3. **执行细化**：把"月末整笔下单"改为 VWAP / TWAP 算法分单，并模拟冲击成本（论文中 0.1% 滑点是简化值）
4. **监控告警**：实盘 IR 每日跟踪，连续 N 天偏离回测 IR 触发模型重训或人工接管

### Q22: 0.1% 双边手续费 + 滑点是否过于乐观？

不算乐观但偏理想化。A 股 ETF 通常综合费率约 0.1-0.2% 单边，加上市场冲击成本，月度调仓真实成本约 0.15-0.25% 单边。论文采用 0.1% × 2 = 0.2% 双边是机构券商通道的下限估计，论文中明确披露并通过 §5.9 换手率约束验证。

### Q23: LLM API 调用涉及数据出境合规吗？

新闻文本本身来自公开网站（东方财富），不涉及个人隐私或非公开数据。Claude API 调用通过 Anthropic 官方 endpoint，未涉及任何个人投资者账户、持仓等敏感信息。本文未把 LLM 用于客户报告生成或个性化推荐场景，合规风险较低。如商用扩展，需额外考虑跨境数据传输的境内监管要求。

### Q24: 用 GPT 等闭源 LLM 是否影响研究可重复性？

是。本研究的对应方案：
1. 通过 SHA-256 缓存把同 prompt + 同模型版本的输出锁定为可复现的 JSON
2. 模型版本号写入 `.env`（claude-opus-4-7 / claude-haiku-4-5），可追溯
3. 长期版本：未来计划对照开源 FinGPT / Qwen-Finance 模型版本，提供真正可完全离线复现的备选管线

### Q25: A 股 2024-2025 单边上涨样本，结论是否能外推到熊市？

部分能。论文长周期实验 §5.2 覆盖 2015-2024 含多个牛熊周期，约束 LightGBM IR 1.69 是穿越熊市的稳健数字；短周期 17 个月只是创新点 demo。严格 OOS 实验 §5.10 用 2025（含部分调整期）测试，IR 2.86 仍维持。但极端熊市（如 2018 / 2022）下策略表现需要更多长样本验证。

### Q26: 你的工作有哪些可商业化路径？

四条：
1. **舆情打分 API 服务**：C1 管线打包为面向公募 / 私募的 SaaS（替代 Wind / Bloomberg 情感数据）
2. **不确定性感知组合优化器**：C3 的置信加权 QP 可作为 PB / 券商投顾的策略加分项
3. **轻量 Stacking 集成 SDK**：C2 的代码可作为初创量化团队的开源 baseline，规避高昂深度学习算力
4. **教育 / 培训**：完整实验链路可作为高校量化金融课程的 case study

### Q27: 跟主流公募指增产品（如易方达 / 富国 / 中欧）相比有何差距？

主流公募 IR 一般 0.8-1.5（来源：基金年报），本文长周期约束 LightGBM IR 1.69、宏观增强 IR 2.45 相对偏高。差距：
1. 公募有严格的 0.5% 内日波动 / 周报跟踪要求，回撤监管更严
2. 公募规模通常 10-100 亿，市场冲击远大于本文回测假设
3. 公募考核以 3 年滚动相对排名为主，本文短期 IR 不能直接对应"长期超额"

本文成果应理解为"研究级 baseline"，而非"实盘可比指标"。

### Q28: Stacking 击败 LightGBM 仅 1.4%，统计显著吗？

是临界显著。Stacking IR 5.92 vs LightGBM IR 5.84，差距 0.08 = 0.6 σ（用 §5.12 LightGBM seed std=0.13 度量）。在 5-seed 重复试验上未做正式 t-test，但 IR 单向高的概率约 70%（非纯随机）。论文如实在 §5.6 标注"小幅但稳定"，并未声称统计强显著。下一步可用 30+ seed 并跑 Wilcoxon test 加强。

### Q29: Conformal Prediction 反向规律会不会只是 LightGBM 自身过拟合？

存在该可能。§5.7 反向规律本质上是 conformal 置信信号与真实 alpha 的负相关，根源可能是：
1. LightGBM 对训练集尾部样本过拟合 → 残差被低估 → conformal 区间过窄 → 该样本被标为"高置信"
2. 实际预测时这些样本反而 IR 低（过拟合点）

论文 §5.7.3 Mondrian 真实数据复测发现行业分组校准未矫正反向规律，进一步支持"源于残差分布异质性"而非"行业系统性偏差"的假设。未来可换用 Random Forest 或 NN 作 base 模型，验证反向规律是否 LightGBM 独有。

### Q30: 这个项目花了多少时间？分阶段成本？

总耗时约 5-6 个月（2026.01-2026.05）：
1. 项目启动 + 数据接入（2 月）：~3 周
2. MVP 基线 + LightGBM 增强（3 月）：~4 周
3. 中期检查 + 长周期实验（4 月）：~4 周
4. 4 大创新点重构 + 论文撰写（5 月）：~6 周

LLM API 累计成本 < 1 USD（haiku 主、opus 偶用）。硬件成本：Apple Silicon Mac 单机，无 GPU 投入。

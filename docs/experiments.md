# 实验设计

## 实验目标

围绕“指数增强是否有效、机器学习是否增益、外部数据是否提升稳健性、风险约束是否必要”四个问题建立实验矩阵。

## 通用设置

- 股票池：按调仓日可得的沪深300成分股
- 调仓频率：月度
- 基准：沪深300指数
- 标签：下一调仓周期个股超额收益
- 回测方式：滚动训练、滚动预测、统一费用假设

## 实验一：基线对照

### 目的

验证多因子打分策略是否能在不使用机器学习的情况下稳定跑赢基准。

### 设置

- 输入：价值、质量、动量、低波动因子
- 方法：因子标准化后等权或分组加权合成总分
- 组合：按得分筛选股票并施加基础权重约束

### 需要输出

- 基准净值
- 多因子基线净值
- 超额净值
- 风险收益指标表

## 实验二：机器学习增强

### 目的

验证 `LightGBM` 是否能优于固定因子打分。

### 设置

- 输入：基线因子 + 外部数据关闭
- 方法：使用滚动窗口训练 `LightGBM`
- 输出：下一期个股超额收益预测值
- 组合：依据预测值构建增强组合

### 对比组

- `baselineScore`：多因子固定打分
- `lightgbmAlpha`：机器学习预测超额收益

### 关注指标

- 年化超额收益
- 信息比率
- 最大回撤
- 稳定性

## 实验三：风险约束有效性

### 目的

验证组合优化和风险约束是否能让策略更符合“指数增强”定位。

### 设置

对同一组预测信号分别构建两种组合：

- `unconstrainedPortfolio`：只根据得分或预测收益排序配置
- `constrainedPortfolio`：加入跟踪误差、行业偏离、个股上限和换手率约束

### 判断标准

- 是否明显降低跟踪误差
- 是否改善回撤或换手
- 是否在可接受收益损失下提高稳健性

## 实验四：外部数据增益

### 目的

验证结构化外部数据是否能提升不同市场状态下的策略适应性。

### 设置

- 基础特征：多因子特征
- 增强特征：`northboundNetInflow`、`m2Yoy`
- 模型：同样使用 `LightGBM`

### 对比组

- `factorOnlyModel`
- `factorWithExternalModel`

### 重点分析

- 整体收益是否改善
- 回撤期表现是否更稳
- 在流动性宽松或偏紧阶段的表现差异

## 实验五：消融实验

### 目的

验证各模块的实际贡献，防止论文结论停留在经验判断。

### 消融维度

- 去掉价值因子
- 去掉质量因子
- 去掉动量因子
- 去掉低波动因子
- 去掉外部数据
- 去掉风险约束

### 输出

- 各消融版本指标表
- 相对完整模型的性能变化

## 推荐结果展示格式

### 表格

- 总体绩效对比表
- 风险指标对比表
- 不同年份分段表现表
- 消融实验结果表

### 图形

- 组合净值曲线
- 超额净值曲线
- 回撤曲线
- 特征重要性条形图
- 年度超额收益柱状图

## 论文证据链

建议最终按照以下逻辑组织实验结论：

1. 多因子基线优于纯基准
2. 机器学习优于静态打分
3. 风险约束让策略更像“可投资的指数增强”
4. 外部数据提升模型在不同市场状态下的稳健性

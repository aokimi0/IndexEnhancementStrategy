\chapter{引言}

\section{研究背景与动机}
在全球资本市场的演进中，指数增强（Smart Beta / Index Enhancement）策略作为一种兼具被动投资低成本与主动管理超额收益潜力的投资工具，日益受到机构与个人投资者的青睐。Smart Beta 策略试图在完全被动的指数跟踪与完全主动的证券选择之间寻求平衡，通过系统性的量化方法对标的指数进行适度偏离，从而实现 ``Beta 稳健、Alpha 突出'' 的投资目标。

本课题以中国 A 股市场的核心基准——\textbf{沪深 300 指数}为实证标的，全面展开量化增强算法的优化设计与系统落地。

\section{A 股市场的微观结构与非有效性}
在构建针对中国 A 股市场的量化策略时，必须充分考量其独特的微观结构与宏观环境。相比成熟市场，A 股呈现出显著的非有效市场（Inefficient Market）特征：
\begin{itemize}
    \item \textbf{投资者结构与情绪驱动}：A 股市场中个人投资者占比较高，短期资金博弈频繁，容易产生大量错误定价（Mispricing）机会。
    \item \textbf{政策导向与宏观敏感度}：中国资本市场受宏观政策、行业监管及流动性环境影响明显，纯微观财务模型存在局限，需引入宏观状态变量以捕捉系统性风险偏好切换。
    \item \textbf{产业结构与基准特征}：沪深 300 指数作为大盘蓝筹代表，成分股对宏观经济和信贷周期高度敏感。
\end{itemize}

\section{本文研究贡献}
\label{sec:contributions}
针对沪深 300 指数增强场景，本文以\emph{算法创新}与\emph{工程加速}为核心，将大语言模型、集成学习、统计学习与高性能计算等计算机科学方向的前沿方法系统性地嵌入经典 Smart Beta 策略框架，具体贡献包括：

\begin{enumerate}
    \item \textbf{C1：基于 Claude Opus 4.7 的中文舆情情感因子}。设计了一条 LLM-as-a-Service 管线（SHA-256 缓存 + 硬性预算守门 + 双通道路由），将 LLM 从昂贵研究工具转为可控成本的日频 alpha 来源；实测单条新闻打分 $5.2\times 10^{-4}$ USD，与传统价值/质量/动量因子语义互补\cite{Tetlock2007Sentiment,Yang2023FinGPT,Wu2023BloombergGPT}（详见 §\ref{sec:sentiment_results}）。

    \item \textbf{C2：异构轻量多模型 Stacking 集成}。在 LightGBM\cite{Ke2017LightGBM} 基础上同步引入 XGBoost\cite{Chen2016XGBoost}、轻量 GRU\cite{Cho2014GRU} 与 Ridge 等异构 L1 模型，通过 OOF KFold + MLP 元学习器自适应融合\cite{Wolpert1992}；全部参数量 $\le$ 百万级、CPU 友好；带约束情境下 IR 5.92 小幅但稳定击败单 LightGBM IR 5.84（详见 §\ref{sec:final_comparison}）。

    \item \textbf{C3：Conformal Prediction 不确定性量化与置信加权 QP}。将 Split / Mondrian CP\cite{Vovk2005Conformal,Romano2019CQR,Angelopoulos2021Gentle} 与本土化二次规划组合优化器耦合，提出三种置信加权方案；实测覆盖率与理论 90\% 偏差恒定 -9 pp（与 $\alpha$ 取值无关），并揭示 A 股低信噪比下 ``高置信即过拟合'' 的反向规律（详见 §\ref{sec:conformal_results} 与 §\ref{subsec:alpha_sensitivity}）。

    \item \textbf{C4：Numba JIT + joblib 并行的高性能回测引擎}。将按日 Python 循环重写为 Numba\cite{Lam2015Numba} JIT 编译的 NAV 累乘核 + joblib 并行的消融框架；Kernel 级加速 130-310$\times$、Engine 级加速 9.84$\times$、数值偏差 $< 10^{-15}$（详见 §\ref{subsec:c4_kernel_vs_engine}），直接呼应课题书所提 ``传统策略计算量大、优化过程耗时长'' 的核心痛点。
\end{enumerate}

\chapter{文献综述与理论基石}

\section{主动管理基本定律与传输系数（TC）}
量化主动管理的数学基础由 Grinold\cite{Grinold1989} 的``主动管理基本定律''首次奠定。其将信息比率（$IR$）拆解为预测能力（$IC$）与投资广度（$N$）的乘积：$IR = IC \cdot \sqrt{N}$。Ding 与 Martin\cite{Ding2017} 进一步指出，盲目套用原始基本定律会高估实盘 IR，因为现实中资产残差具有相关性且横截面信息非平稳。

Clarke 等\cite{Clarke2002} 引入了传输系数（Transfer Coefficient, $TC$），将基本定律拓展为 $IR = TC \cdot IC \cdot \sqrt{N}$；Grinold 与 Kahn\cite{Grinold2000} 的经典教材进一步将该框架系统化为现代主动管理的方法学基础。研究表明，禁止卖空及行业、换手率约束会严重阻碍 Alpha 信号转化为主动权重。因此，策略的核心在于在严苛的多面体约束空间内寻找使 $TC$ 最大化的可行解。

\section{资产定价模型的中国实证挑战}
Fama 与 French\cite{Fama2015} 提出的五因子模型在美股极具解释力。但在中国 A 股，受宏观调控与信贷干预影响，投资因子（CMA）往往出现严重冗余；散户主导的微观结构使流动性与动量溢价更为显著。因此，直接套用西方框架容易失效，需将流动性因子和宏观特征作为重点主攻方向。Chen 等\cite{Chen2024DeepLearningAP}（Management Science 2024）的深度学习资产定价框架进一步证实，结合宏观状态变量与非线性模型可显著改善 A 股截面预测。

\section{机器学习在收益预测中的范式迁移}
Gu 等\cite{Gu2020} 的开创性文献对机器学习在实证资产定价中的应用确立了最高基准，证明了非线性集成树模型与神经网络能够精准捕获因子间的条件触发与高阶交互作用，在预测精度上全面碾压传统线性回归。针对 A 股市场信噪比极低的特征，Yang\cite{Yang2025} 证实了 LightGBM 在特征捆绑与单边采样上的工程优势，能够有效提取异常换手率、特质波动率等微观结构信号，显著改善样本外的泛化表现。

\section{协方差缩减与误差最大化的修正}
在组合优化中，直接使用历史收益计算的样本协方差矩阵往往呈病态特性，易导致优化器产生极端的``角点解''，被 Michaud\cite{Michaud1989} 称为``误差最大化''（Error-Maximization）。Ledoit 与 Wolf\cite{Ledoit2004} 提出的线性收缩估计法（Shrinkage Estimator），通过将高方差的样本协方差矩阵向结构化目标矩阵加权收缩，可有效平滑极值系数并降低实现的跟踪误差。

\section{大语言模型在金融文本理解中的兴起}
Tetlock\cite{Tetlock2007Sentiment} 较早通过词典法系统量化了媒体语调对美股收益与成交量的预测作用，奠定了文本情感作为另类 alpha 源的实证基础。深度学习时代后，FinBERT、FinGPT\cite{Yang2023FinGPT} 与 BloombergGPT\cite{Wu2023BloombergGPT} 等基于金融语料持续预训练的判别/生成模型相继涌现，但训练与部署成本对中小研究团队构成门槛。近期 Claude\cite{Anthropic2026Opus47} 等闭源大模型以 API 形式提供强语义理解能力，催生了 \emph{LLM-as-a-Service} 范式，使研究者得以通过结构化 prompt 直接获取细粒度极性、强度与主题标签。Lopez-Lira 与 Tang\cite{LopezLira2024ChatGPT} 较早实证 ChatGPT 通过新闻头条即可形成超越简单时序模型的收益预测能力；Lan 等\cite{Lan2025FinChinaSA} 进一步证明大模型在中文细粒度财经情感分析任务上显著超越传统词典与 BERT 类模型；Open-FinLLMs\cite{Huang2024OpenFinLLMs} 则开源了多模态金融 LLM，提供本地化部署可能性。本文 C1 舆情因子管线直接采纳该范式。

\section{Stacking 集成与异构模型融合}
Wolpert\cite{Wolpert1992} 提出的 Stacked Generalization 是异构模型融合的奠基性工作，其核心思想是用一个元学习器在多个基学习器的输出之上学习最优组合方式，相较简单平均或投票更具数据驱动的自适应性。López de Prado\cite{Lopez2018Stacking} 进一步指出金融机器学习因样本依赖、非平稳与低信噪比等特殊性，更依赖异构集成以缓解单一模型在不同 regime 下的鲁棒性不足。Mekelburg 与 Strauss\cite{Mekelburg2024Pooling}（JEF 2024）从实证角度证实，pooling 与 winsorizing 机器学习预测可显著改善高维收益预测的稳健性。现代实践中通常以树模型（LightGBM\cite{Ke2017LightGBM}、XGBoost\cite{Chen2016XGBoost}）、序列模型（GRU\cite{Cho2014GRU}）与线性模型（Ridge）构成异构 L1 模型族，并配合 KFold OOF 训练规避标签泄漏，再由 MLP 或线性元学习器输出最终预测。

\section{Conformal Prediction 与不确定性量化}
Vovk 等\cite{Vovk2005Conformal} 提出的 Conformal Prediction (CP) 框架在仅假设可交换性（exchangeability）的弱条件下，即可为任意点预测构造具有有限样本边际覆盖率保证的预测区间。Romano 等\cite{Romano2019CQR} 提出的 Conformalized Quantile Regression (CQR) 进一步借助分位数回归改善条件覆盖率，在异方差与重尾场景下显著优于经典 Split CP。Angelopoulos 与 Bates\cite{Angelopoulos2021Gentle} 系统梳理了 CP 在分类与回归任务上的实践范式。然而金融时序场景下可交换性假设受截面相关性与时间漂移所破坏，A 股低信噪比环境会放大覆盖偏差，CP 的工程化落地仍是较新的研究方向。Kato\cite{Kato2024CPPS} 进一步将 CP 直接嵌入组合选择，提出 Conformal Predictive Portfolio Selection 范式，与本文 C3 高度相关。

\section{高性能数值计算与回测加速}
Lam 等\cite{Lam2015Numba} 提出的 Numba 借助 LLVM 将 Python 数值代码即时编译为机器码，使解释型语言获得接近 C/Fortran 的执行性能。量化回测中按日循环、滚动窗口与组合再平衡步骤的向量化收益有限，纯 Python 实现难以同时兼顾可读性与吞吐率；而依赖 GPU 的方案对资源受限场景并不友好。joblib 与 Dask 则提供了进程级与跨节点的任务并行化能力。本文将 Numba JIT 与 joblib 并行结合，旨在为单机 CPU 环境下的量化回测引擎给出一条可复用的工程范式。

\section{2026 前沿对照：LLM Agent、MoE、扩散模型与自适应 CP}
\label{sec:2026_sota}
作为定位本文创新点的参照系，本节梳理 2025-2026 年同主题的代表性前沿工作，明确本文在工程可复现性与算法新颖性之间的折衷。

\textbf{LLM Agent 与多智能体交易范式}：FinMem\cite{Yu2024FinMem} 在 LLM trading agent 中加入分层记忆与角色画像设计；AlphaAgent\cite{Tang2025AlphaAgent}（KDD 2025）用 LLM 驱动正则化 alpha 挖掘以对抗 alpha decay；StockBench\cite{Wang2026StockBench} 提出沾染洁净（contamination-free）的多月度真实交易评测协议，对 GPT-5 / Claude-4 等前沿 LLM 作为自主交易 agent 进行评估，发现多数 agent 仍难稳定击败 buy-and-hold 基线；QuantAgent\cite{Li2025QuantAgent} 进一步设计了价格驱动的多智能体 LLM 高频交易框架，在跨资产 1H/4H K 线上取得最高 80\% 方向预测准确率；Karim 等\cite{Karim2026AgenticRegime} 则提出了统一的 LLM 信号 + regime-aware 组合优化 agentic 框架。这些工作展示了 LLM agent 作为完整决策主体的潜力，但调用频次与成本对资源受限场景构成显著门槛；本文 C1 退而求其次，将 LLM 作为离线的语义抽取层，把可控成本作为首要工程约束。

\textbf{中文 A 股深度学习预测的最新范式}：MASTER\cite{Li2024MASTER}（AAAI 2024）提出 market-guided stock transformer 用动态市场信号引导个股预测；Ji 等\cite{Ji2025MMFTrans} 提出宏观-微观信息融合的多模态 transformer 框架。两者代表了 A 股深度学习的最新算法路线，与本文 C2 的轻量级 Stacking 框架形成参数规模与可解释性的鲜明对比。

\textbf{Mixture-of-Experts (MoE) 范式}：MIGA\cite{Zhou2024MIGA} 提出按风格分组的 MoE 路由架构，在 CSI300 上取得 24\% 年化超额收益，刷新中国宽基指数 ML 增强 SOTA；LLMoE\cite{Li2025LLMoE} 进一步用 LLM 作为 MoE 路由器，融合价格与新闻头条选择最适合的专家模型；FTS-Text-MoE\cite{Tanaka2025FTSTextMoE} 用多模态 MoE 融合数值与文本预测；AlphaMix\cite{Sun2022AlphaMix} 则以两阶段 MoE 框架显式建模不确定性。这一线索表明，异构集成的下一站是\emph{条件化路由}而非简单加权融合。本文 C2 的 MLP 元学习器可视为该路线的轻量级实现，其端到端结构便于 CPU 训练与可解释性。

\textbf{扩散模型与场景生成}：Yin 等\cite{Xu2025DiffusionFactor} 提出 Diffusion Factor Model，将因子结构嵌入扩散过程的 score function，在高维小样本场景下生成可用于均值-方差优化的合成收益；Diffolio\cite{Lee2025Diffolio} 则用层次注意力 + 相关性正则的条件扩散模型直接输出组合预测分布。这是 2025 年新兴的``生成式资产定价''路线，相较 Ledoit-Wolf 缩减提供了更灵活的协方差估计，但训练样本与算力需求仍较高。

\textbf{自适应/在线 Conformal Prediction}：Gibbs 与 Cand\`es\cite{Gibbs2021ACI} 提出 Adaptive Conformal Inference (ACI)，通过在线调整 miscoverage 率适应分布漂移；Xu 与 Xie\cite{Xu2023SPCI}（ICML 2023）的 Sequential Predictive CP 引入残差自相关建模显著改善时序覆盖；Hallberg\cite{Hallberg2024MultiStepACI} 扩展到多步在线 ACI；Aydin 等\cite{Aydin2025TCP} 提出的 Temporal Conformal Prediction 在分位回归之上叠加衰减学习率，专为金融时序非平稳性设计；Yang 等\cite{Yang2025ECI}（ICLR 2025）的 Error-quantified Conformal Inference 以平滑 EQ 反馈替代二值 miscoverage，加速适配分布漂移；CPTC\cite{Sun2025CPTC}（NeurIPS 2025）引入显式 change point 状态预测；ResCP\cite{Neglia2026ResCP} 借助 reservoir computing 实现 training-free 的 CP。这些工作在覆盖率自适应性上明显优于经典 Split CP，是本文 C3 的直接竞争对手。

\textbf{元学习与在线组合}：Meta-LMPS-online\cite{Wang2025MetaLMPS} 用 MAML 元学习初始化的混合策略权重在线适配非平稳市场；Lu 等\cite{Lu2026SemiSandwich} 提出 CVaR 教师 + 半监督 sandwich training 的 Bayesian/Deterministic 学生组合优化代理，应对 label scarcity 与 regime shift；国金金工 TSGRU+LGBM\cite{Guojin2026TSGRU} 报告则展示了产业界 2026 年 A 股指增的主流路线：基于 TimeMixer 改进的时序 GRU 提取隐向量后由 LightGBM 集成，配合月度组合优化。

综上，本文 C1-C4 的定位是\emph{覆盖广度与工程可复现性优先}：在四个相互正交的子方向上以最小依赖与可控成本实现完整管线，而非在任一子方向追求 SOTA 算法。第 §\ref{sec:future_work} 节将给出与上述前沿融合的具体路线图。

\chapter{Smart Beta 策略重构与核心因子设计}

策略的核心是依据 A 股宏观与微观特性，构建防御与进攻兼备的特征面板，而非盲目堆砌数据。

\section{价值与质量因子（防御与抗周期）}
结合 A 股红利底仓逻辑，本文在价值维度同时保留传统 PE/PB 估值的倒数形式 \texttt{ep\_ttm}（市盈率倒数）与 \texttt{bp}（市净率倒数），并引入\textbf{自由现金流收益率（FCF Yield）}与\textbf{股息率（Dividend Yield）}作为补充。自由现金流相较账面净利润更能反映企业真实的现金创造能力，可有效过滤掉以应收账款扩张为主的虚高利润型公司。

质量维度选用 \texttt{roe}（净资产收益率）、\texttt{grossprofitmargin}（毛利率）、\texttt{netprofitmargin}（净利率）、\texttt{yoynetprofit}（净利润同比增速）、\texttt{assetturnover}（资产周转率）、\texttt{cfotoor}（经营现金流 / 营业收入）共 6 个会计科目原值，全部来自 baostock 季度财务接口，并按 \texttt{merge\_asof} 向前对齐到日频面板。该 8 个因子（价值 2 + 质量 6）构成本文的\emph{基本面静态底仓}，在长周期回测中承担稳健性与防御功能。

\section{动量与微观结构因子（捕捉题材与情绪）}
鉴于 A 股动量与反转频繁，本文引入中高频的技术与微观结构因子共 4 个：\texttt{ret\_20}（20 日累计收益率）、\texttt{ret\_60}（60 日累计收益率）、\texttt{volatility\_20}（20 日日收益年化波动率）、\texttt{turnover\_20}（20 日平均换手率）。其中 ret\_20 / ret\_60 同时刻画短期与中期动量，volatility\_20 用于在趋势末端识别尾部风险，turnover\_20 则反映流动性热度与情绪聚集。

形式化定义：设 $P_{i,t}$ 为股票 $i$ 在 $t$ 日的收盘价，则：
\[
\text{ret\_20}_{i,t} = \frac{P_{i,t}}{P_{i,t-20}} - 1, \qquad
\text{volatility\_20}_{i,t} = \sqrt{252} \cdot \text{std}_{s\in[t-20,t]}\left(\frac{P_{i,s}}{P_{i,s-1}} - 1\right)
\]
微观结构因子能敏锐捕获由情绪交易引致的短期错误定价，与基本面因子在时间尺度上互补。

\section{政策与宏观情绪因子的降维处理（条件触发机制）}
本文引入 3 个结构化宏观因子：\texttt{northbound\_net\_inflow}（北向资金当日净流入金额，单位亿元）、\texttt{m2\_yoy}（中国 M2 货币供应同比增速，月度发布、按 \texttt{merge\_asof} 前向填充到日频）、\texttt{cn\_spread\_10y\_2y}（中国 10 年期与 2 年期国债到期收益率利差，作为期限结构倾斜指标）。这三个变量分别从\emph{外部资金偏好、广义流动性、利率期限结构}三个维度刻画 A 股的宏观背景。

它们作为宏观状态变量（Regime Indicators），并非用于直接选股，而是赋予非线性模型（如 LightGBM）\emph{动态风格轮动}（Dynamic Style Rotation）能力——例如在流动性宽松期（M2 高、利差扩大）模型可自动加大高 beta 因子的暴露；在北向资金持续净流出阶段模型可减少进攻性因子敞口。该机制的实证有效性见 §\ref{sec:macro_lw} 的宏观增益对比与 §\ref{sec:strict_oos} 的严格 OOS 验证。

\section{因子预处理与异常值控制}
为使 §\ref{sec:contributions} 列出的 15 个数值因子在不同时间截面上具备可比性，本文采用三步流水线：

\noindent\textbf{(1) MAD 缩尾}。每日截面对每个因子 $f$，计算中位数 $\text{med}(f)$ 与绝对中位差 $\text{MAD}(f) = \text{med}(|f - \text{med}(f)|)$，把超出 $[\text{med} - k\cdot \text{MAD}, \text{med} + k\cdot \text{MAD}]$（$k=3$ 默认）的值截断到边界，有效抑制重尾。

\noindent\textbf{(2) Z-Score 标准化}。在 MAD 缩尾后的截面上做减均值除标准差：$\tilde f_{i,t} = (f_{i,t} - \mu_t) / \sigma_t$，使各因子在数值量级上对齐。

\noindent\textbf{(3) 行业中性化}（Industry Neutralization）。在 (2) 的基础上，若面板中含 \texttt{industry\_name}（申万一级行业），改为按 $[\text{trade\_date}, \text{industry\_name}]$ 双重分组做 Z-Score；这相当于在每个截面对每个行业内独立做归一化，从而\emph{隔离行业间的天然估值差异}（例如银行业 \texttt{bp} 系统性偏高、TMT 行业 \texttt{roe} 系统性偏低）。

\noindent\textbf{(4) 标签构造}。对预测目标，本文不用绝对收益而用相对沪深 300 的超额收益：$\text{label\_excess\_return\_20d}_{i,t} = (P_{i,t+20}/P_{i,t} - 1) - (I_{t+20}/I_t - 1)$，其中 $I_t$ 为沪深 300 指数收盘价。该标签消除了系统性 beta 的影响，让模型聚焦于截面 alpha 信号。

\noindent\textbf{(5) 因子族总览}。本文最终使用的 15 个数值因子按语义分为 6 组：价值（2）、质量（6）、技术与微观结构（4）、外部宏观（3），共同构成 \texttt{src/factors/engine.py} 中的 \texttt{feature\_groups()} 字典，可被 \texttt{src/pipelines/run\_feature\_ablation.py} 按分组做消融。

\chapter{模型选型与组合优化框架}

本章对应 §\ref{sec:contributions} 的四项贡献，依次介绍四块新增模块的算法设计与工程实现。

\section{多因子基础层（LightGBM 主回归器）}
本文保留 LightGBM\cite{Ke2017LightGBM} 作为主回归器，特征采用 §\ref{subsec:data_quality} 之前章节定义的 15 个数值因子（见 §3 因子设计）。模型超参数固定为 \texttt{n\_estimators=300, learning\_rate=0.05, num\_leaves=31, subsample=0.8, colsample\_bytree=0.8}，训练标签为 \texttt{label\_excess\_return\_20d}。所有滚动训练窗口默认 12 个月（长周期）/ 6 个月（短周期），月度重训。该层提供本文所有后续创新点（C1-C3）所依赖的 baseline 预测信号。

\section{C1：基于 Claude Opus 4.7 的舆情情感因子}
\subsection{管线设计}
新闻文本来源于东方财富 \texttt{stock\_news\_em} 接口（沪深 300 成分股个股新闻流），日均产出约 10 条/股；公告与研报留待后续扩展。对每只股票，按 \emph{publish\_time} 升序聚合到批量 prompt（每批 10 条），调用 Claude API 输出严格 JSON：
\begin{verbatim}
{ "id": int, "polarity": -1~1, "intensity": 0~1,
  "topic": "earnings/policy/risk/macro/industry/operation/other",
  "explain": "<=20 zi" }
\end{verbatim}

\subsection{成本控制}
为避免大规模 LLM 调用的成本失控，本文采用四道防线：(a) 缓存层用 SHA-256(\texttt{text+model+prompt\_version}) 作 key 落 parquet，二次实验直接命中；(b) 默认走 \texttt{claude-haiku-4-5} 快速通道（输入 0.0008 \$/K tok、输出 0.004 \$/K tok），仅在关键样本子集上开启 \texttt{claude-opus-4-7}\cite{Anthropic2026Opus47}；(c) 每批 10 条新闻一次 prompt，最大化 token 利用率；(d) \texttt{BudgetTracker} 在每次请求前累计 USD，超过 \texttt{ANTHROPIC\_MAX\_USD} 立刻抛 \texttt{BudgetExceededError}。

\subsection{日频聚合}
对同一只股票同一交易日内多条新闻，按时间衰减加权聚合：
\[
\text{sentiment}_{i,t} = \frac{\sum_k \text{polarity}_{i,t,k} \cdot \text{intensity}_{i,t,k} \cdot e^{-\Delta h/24}}{\text{count}_{i,t}}
\]
其中 $\Delta h$ 为该条新闻发布时间距 16:00 收盘的小时差；当日 16:00 之后发布的新闻计入下一交易日，避免未来信息泄露。同时输出 5 日移动平均 \texttt{sentiment\_ma5} 作为低频通路。

\section{C2：异构轻量多模型 Stacking 集成框架}
\subsection{L1 模型族}
\begin{itemize}
    \item \textbf{LightGBM}\cite{Ke2017LightGBM}：参数同 §4.1。
    \item \textbf{XGBoost}\cite{Chen2016XGBoost}：\texttt{n\_estimators=300, max\_depth=6, tree\_method='hist'}，与 LightGBM 同特征但生长策略不同。
    \item \textbf{轻量 GRU}\cite{Cho2014GRU}：PyTorch CPU 实现，输入每只股票过去 20 日因子序列 $\mathbb{R}^{B\times 20\times d}$，单层 GRU $h=32$，FC 投影到标量，参数量约 5K；训练 \texttt{AdamW, lr=1e-3, batch=512, epochs=20, early\_stop=3}。
    \item \textbf{Ridge}：含 \texttt{StandardScaler} + \texttt{RidgeCV}（alpha 网格 [0.1, 1, 10, 100]）。
\end{itemize}

\subsection{元学习器与 OOF 训练}
对每个调仓窗口 $t$，先用 3 折 KFold 在训练子集上生成各 L1 的 Out-of-Fold (OOF) 预测，得到\emph{元特征矩阵} $Z\in\mathbb{R}^{n_{\text{train}}\times 4}$；再用线性（默认）/ MLP / 简单平均三选一拟合 $Z$ 到标签 $y$。测试日每个 L1 在全量训练子集上 refit 后输出预测 $\hat Z\in\mathbb{R}^{n_{\text{test}}\times 4}$，元学习器再输出最终 \texttt{ml\_score}。该框架允许元学习器自动识别相关性高的 L1 模型并施加\emph{负向校正}\cite{Wolpert1992,Lopez2018Stacking}。

\section{C3：Conformal Prediction 不确定性量化与置信加权组合优化}
\subsection{Split / Mondrian Conformal Prediction}
对每个滚动窗口，将训练子集按 $1-r:r$（$r=0.3$）划分为 train\_proper 与 calibration set。LightGBM 在 train\_proper 上拟合后，计算 calibration 集残差 $r_i=|y_i-\hat y_i|$，取分位数 $q_\alpha=\text{Quantile}_{(n+1)(1-\alpha)/n}(r)$\cite{Vovk2005Conformal}（$\alpha=0.1$，对应 90\% 区间）。测试样本预测为 $[\hat y - q_\alpha,\, \hat y + q_\alpha]$，置信度 $c_i=1/(2q_\alpha+\epsilon)$ 归一化到 [0,1]。Mondrian 版本按申万一级行业分组计算 $q_\alpha$，提升条件覆盖率\cite{Romano2019CQR,Angelopoulos2021Gentle}。

\subsection{三种置信加权方案}
扩展原 \texttt{ConstrainedPortfolioOptimizer}：
\begin{itemize}
    \item \texttt{alpha\_scale}：$\alpha_i' = \alpha_i \cdot c_i^\beta$，$\beta=1.0$ 默认；
    \item \texttt{candidate\_filter}：仅置信度 top 70\% 进 QP 候选池，其余权重置 0；
    \item \texttt{objective\_penalty}：QP 目标新增 $-\gamma\sum_i (1-c_i)w_i^2$，$\gamma=0.1$ 默认。
\end{itemize}

\section{C4：Numba JIT + joblib 并行的高性能回测引擎}
\subsection{Numba JIT NAV 累乘核}
将原 \texttt{BaselineBacktestEngine.\_build\_nav} 中的按日 Python 循环抽取为 \texttt{compute\_nav\_loop} 核函数，用 \texttt{@numba.njit(cache=True)} 装饰\cite{Lam2015Numba}，输入为 $(n_d\times n_s)$ 的日收益矩阵、权重矩阵、$(n_d,)$ 的基准收益、调仓掩码与单边换手率；输出 6 路一维 \texttt{float64} 序列。同时实现纯 NumPy 等价版本作为 fallback（当 numba 未安装时降级）。

\subsection{joblib 并行实验框架}
\texttt{src.backtest.parallel} 提供 \texttt{run\_in\_parallel} / \texttt{cached\_to\_disk} / \texttt{parallel\_backtest} 等工具，将消融实验、训练窗口探索等独立任务以 \texttt{joblib.Parallel(loky)} 并行化；模型训练中间产物用 \texttt{joblib.dump} 缓存到 \texttt{data/cache/}，避免重复昂贵训练。

\section{二次规划与协方差缩减（沿用）}
\texttt{cvxpy}\cite{Ledoit2004} 构建的二次规划求解器保持不变：
\begin{itemize}
    \item \textbf{目标}：$\max\;\alpha^\top w - \lambda(w-w_b)^\top\Sigma(w-w_b) - \kappa\|w-w_{\text{prev}}\|_1$；
    \item \textbf{约束}：年化跟踪误差 $\le 8\%$、行业偏离 $\le \pm 2\%$、单股权重 $\le 5\%$、月度单边换手 $\le 20\%$；
    \item \textbf{协方差}：Ledoit-Wolf 缩减估计 + ridge 项 + 最小特征值修正以保正定；
    \item \textbf{求解器回退}：OSQP $\to$ CLARABEL $\to$ SCS，最终失败则降级到 \texttt{previous\_weights}。
\end{itemize}

\subsection{Mondrian Conformal 与 Split Conformal 的对照}
\label{subsec:mondrian_vs_split}
为缓解 Split CP 在 A 股低信噪比环境下的"高置信即过拟合"反向规律，本文同步实现了 Mondrian Conformal Prediction：按申万一级行业分组分别计算 calibration 残差分位数 $q_\alpha$，实现\emph{条件覆盖}。

\textbf{合成数据 demo 观察}：在合成数据上 Mondrian 通过行业分组校准使整体覆盖率向理论 90\% 收敛（提升约 4 个百分点）；更重要的是，\textbf{合成数据下高置信桶 IR 由 Split 的 -0.140 翻转为 Mondrian 的 +0.161}，"高置信即过拟合"的反向规律似乎被矫正。

\textbf{真实数据复测的反转结论}：然而当我们用同一份 Mondrian 实现跑真实 hs300\_panel\_2024\_2025 时（结果见 \texttt{data/processed/conformal\_real\_mondrian\_2024\_2025/}），覆盖率仅由 Split 的 80.9\% 微涨至 81.3\%（提升 0.4 个百分点），高置信桶 IR 反而由 -0.140 进一步恶化至 \emph{-0.205}；整体 baseline 与 objective\_penalty 的 IR 与 Split 完全一致（因为 group 仅影响 calibration，对单点预测无作用）。这说明：
\begin{itemize}
    \item 合成数据 demo 上 Mondrian 矫正反向规律，是因为合成数据的行业残差结构是\emph{人为可分组}的；
    \item \textbf{真实 A 股环境下"高置信即过拟合"反向规律相当稳健}，仅靠行业分组校准无法矫正，需要更强的条件性 CP（如 CQR、Adaptive CP）或彻底改换不确定性度量；
    \item 这印证了本文 C3 的核心实证发现的稳健性，也为未来工作（§\ref{sec:future_work}）指明了具体的方法学改进方向。
\end{itemize}

\chapter{结论与展望}

\section{主要结论}
本文以沪深 300 指数增强为应用场景，从计算机算法与工程加速两个维度提出并实证了四项创新点：
\begin{enumerate}
    \item \textbf{C1（LLM 舆情因子）}：通过 Claude Opus 4.7 / Haiku 4.5 双通道、SHA-256 缓存与硬性预算守门，将 LLM 调用从昂贵的离线服务转化为可控成本的日频 alpha 来源；端到端单次实验成本可压缩到 10 美元以内。
    \item \textbf{C2（异构 Stacking 集成）}：LightGBM + XGBoost + GRU + Ridge 的异构 L1 模型族通过 OOF KFold 与 MLP 元学习器自适应融合；在 2024-2025 短样本上，元学习器自动给同质化最强的 Ridge 模型赋予负向校正权重，体现了 Stacking 在低信噪比金融数据中的自动模型选择能力。
    \item \textbf{C3（Conformal Prediction 置信加权）}：Split / Mondrian CP 与本土化 QP 优化器耦合，三种置信加权方案在短样本上的实测覆盖率与理论 90\% 的偏差控制在 10 个百分点内。本文同时揭示了 A 股低信噪比环境下\emph{高置信度即过拟合}的反向规律，为后续不确定性感知型组合提供了实证依据。
    \item \textbf{C4（Numba JIT 加速）}：将回测核心循环改写为 Numba JIT，实测十年沪深 300 面板上加速 9.84$\times$ 且数值偏差小于 $10^{-15}$；joblib 并行进一步将消融实验加速 1.48$\times$。该工程加速直接呼应了课题书``传统策略计算量大、优化过程耗时长''的核心痛点。
\end{enumerate}

长周期 2015-2024 实证显示，约束型 LightGBM 在叠加宏观外部数据与 Ledoit-Wolf 缩减后，信息比率（IR）由静态多因子的 0.237 跃升至 2.449，最大回撤由 -58.53\% 收敛至 -25.37\%；严格 OOS 验证进一步指出``近期 1 年 $\to$ 次年''的滚动窗口才是 A 股 LightGBM 模型可投资性的关键。

\section{创新点的学科贡献}
不同于将既有经典理论简单本土化的研究路径，本文的四项创新分别对应大语言模型工程化、异构集成学习、统计学习不确定性量化、高性能数值计算四个计算机科学子方向，使得``指数增强''这一传统量化场景获得了\emph{算法与工程双轮驱动}的全新基线。所有实现均在 CPU 环境下完成、参数量控制在百万级以内，避免了对昂贵 GPU 与超大规模深度网络的依赖，对资源受限场景下的量化研究者具备直接复用价值。

\section{局限与展望}
\label{sec:future_work}
当前实验仍受样本规模与外部数据稳定性的双重制约，与 §\ref{sec:2026_sota} 梳理的 2026 前沿工作相比，本文有以下具体升级方向：

\begin{itemize}
    \item \textbf{数据扩展（C1）}：sentiment 因子真实数据覆盖率仅 0.32\%，下一步引入巨潮资讯公告与 Wind 研报扩大语料，并参照 StockBench\cite{Wang2026StockBench} 的 contamination-free 设计避免回测污染。
    \item \textbf{C2 升级为 MoE 路由}：将 MLP 元学习器升级为 MIGA\cite{Zhou2024MIGA} 风格分组 MoE 或 LLMoE\cite{Li2025LLMoE} 的 LLM-as-Router，并在国金金工 TSGRU+LGBM\cite{Guojin2026TSGRU} 框架内做对照。
    \item \textbf{C3 升级为自适应 CP}：尝试 TCP\cite{Aydin2025TCP}、ECI\cite{Yang2025ECI}（ICLR 2025）、CPTC\cite{Sun2025CPTC}（NeurIPS 2025）与 ResCP\cite{Neglia2026ResCP} 等具有 change-point 感知与在线衰减学习率的变体，矫正 §\ref{subsec:alpha_sensitivity} 揭示的 -9 pp 系统性偏差。
    \item \textbf{扩散场景增广}：以 Diffusion Factor Model\cite{Xu2025DiffusionFactor} 或 Diffolio\cite{Lee2025Diffolio} 生成的多场景合成收益替代 Ledoit-Wolf 缩减估计协方差。
    \item \textbf{C4 跨节点扩展}：基于 Dask / Ray 做跨节点参数搜索；调用 LightGBM 的 GPU 后端验证学术与工程 trade-off。
    \item \textbf{LLM Agent 决策融合}：参考 QuantAgent\cite{Li2025QuantAgent} 与 Karim 等\cite{Karim2026AgenticRegime} 的 agentic regime-aware 框架，将 LLM 舆情因子升级为完整的 LLM agent 信号源 + 决策代理；并结合 Meta-LMPS-online\cite{Wang2025MetaLMPS} 实现策略级在线适配。
\end{itemize}

\label{sec:teaching_value}
本研究除作为毕业设计满足学位要求外，还在以下几方面具备直接的教学与开源贡献价值：

\begin{itemize}
    \item \textbf{完整教学样本}：从原始 \texttt{akshare/baostock} 数据接入、因子工程、机器学习训练、组合优化到回测评估的完整可复现链路，可作为后续量化方向同学的入门参考与改造起点。
    \item \textbf{2026 前沿对照表}：§\ref{sec:2026_sota} 系统梳理了 LLM Agent、MoE、Diffusion、自适应 CP 等 5 个方向的 16 篇最新工作，为后续选题与文献综述提供现成的索引。
    \item \textbf{LLM-as-a-Service 工程范式}：本文给出的 SHA-256 缓存 + 硬性预算守门 + 批量 prompt + 双通道 (Haiku / Opus) 模式，可直接套用到其他量化文本理解任务（如分析师报告评分、上市公司公告事件抽取等），将 LLM 从昂贵的离线服务转化为可控成本的日频信号源。
    \item \textbf{统计学习不确定性量化的工程化}：C3 章节给出的 Split / Mondrian CP 与三种置信加权 QP 方案是国内本科毕设阶段较少见的工程化实现，对其他需要 ``置信感知'' 仓位的策略（如商品 / 期权 / FX）具有直接迁移价值。
    \item \textbf{开源代码与文档}：所有代码、数据接入、超参数与实验脚本均在 \url{https://github.com/aokimi0/IndexEnhancementStrategy} 公开；论文配套 \texttt{check\_paper\_health.py} 与 \texttt{generate\_innovation\_charts.py} 工具可被其他论文写作者直接复用。
    \item \textbf{诚实研究规范}：本文同时披露了 sentiment 因子时间移位 demo 的局限（§3.19 in \texttt{experiment_log}）与 Conformal Prediction 在 A 股的反向规律（§\ref{sec:conformal_results}），未掩盖负面或令人困惑的实验结果。这种披露规范对后续研究者复现与改进具有重要价值。
\end{itemize}

\section{实验复现指南}
\label{sec:reproduction}
为方便后续工作复现本文实验，本节列出关键 pipeline 与运行命令。完整代码、数据接入与配置见 GitHub 仓库 \url{https://github.com/aokimi0/IndexEnhancementStrategy}。

\subsection{环境准备}
\begin{verbatim}
conda create -n index-enhancement python=3.11 -y
conda activate index-enhancement
pip install -r requirements.txt
\end{verbatim}
配置 \texttt{.env}（已在 \texttt{.gitignore} 内）：
\begin{verbatim}
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-opus-4-7
ANTHROPIC_FAST_MODEL=claude-haiku-4-5
ANTHROPIC_MAX_USD=20
\end{verbatim}

\subsection{核心实验入口}
\begin{itemize}
    \item \textbf{C1 LLM 舆情}：\texttt{python -m src.pipelines.build\_sentiment\_panel --start 2025-01-01 --end 2025-05-30 --output processed/sentiment\_panel.csv --max-codes 60 --max-usd 8}
    \item \textbf{C2 Stacking}：\texttt{python -m src.pipelines.run\_stacking\_experiment --input processed/hs300\_panel\_2024\_2025\_v2.csv --variants lgbm xgb ridge stacking --use-external-features}
    \item \textbf{C3 Conformal}：\texttt{python -m src.pipelines.run\_conformal\_experiment --input processed/hs300\_panel\_2024\_2025\_v2.csv --schemes baseline alpha\_scale candidate\_filter objective\_penalty --use-external-features}
    \item \textbf{C4 Numba}：\texttt{python -m src.pipelines.benchmark\_engine}
    \item \textbf{五策略最终对比}：\texttt{python -m src.pipelines.final\_strategy\_comparison}
    \item \textbf{论文健康检查}：\texttt{python -m src.pipelines.check\_paper\_health}
    \item \textbf{论文图表生成}：\texttt{python -m src.pipelines.generate\_innovation\_charts}
\end{itemize}

\subsection{硬件与时间预算}
所有实验均在 Apple Silicon M-series CPU 单机完成。完整 C1+C2+C3+C4 实验耗时约：建面板 40 分钟（akshare 限流是主因）、LLM 打分 5 分钟 / 0.31 USD、Stacking 1 分钟（不含 GRU）、Conformal 1 分钟、Numba 基准 30 秒。五策略对比脚本端到端 2.5 分钟。
